# Build e teste no Windows

Dependências: Windows 10/11, Python 3.11+, QEMU para Windows, Android SDK Platform Tools (ADB) e uma imagem Android x86_64 obtida legalmente.

1. Instale QEMU e ADB.
2. Coloque a imagem Android em `images/`.
3. Ajuste `config.json`.
4. Execute `python launcher.py`.
5. Clique em **Iniciar Android**.
